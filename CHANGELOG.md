# Changelog

## 2026.11.19

- Winter tire rules of 47 countries with sources, a recommendation sensor, a "tire change due" binary sensor, a select for the mounted tires and an optional persistent notification.
- Setup from the UI, from YAML, or automatically after the installation (self-discovery).
- Translated into 35 languages. The integration name and the suggested name in the setup follow the language of the Home Assistant server, the country is preselected from the Home Assistant settings or the time zone.
- Supports Home Assistant 2022.8 and newer.
- Versions read `YYYY.MM.DD` for the first build of a day and `YYYY.MM.DD.1`, `.2` and so on for later ones; release tags carry no `v`.
